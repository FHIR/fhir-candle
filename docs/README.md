# fhir-candle documentation

This is the documentation set for **fhir-candle**, a small in-memory FHIR
server for testing and development. The docs are split by audience role:

- **[User docs](user/)** — for people **running, configuring, and calling** the
  server: operators, FHIR client / IG developers, and testers.
- **[Technical docs](technical/)** — for people **building and contributing to**
  the server: contributors and maintainers.

These are plain in-repo Markdown files. There is no docs-site build, no
generator, and no GitHub Pages pipeline — open the files directly here on GitHub
or in your editor.
